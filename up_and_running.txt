Just these steps:

Run the install script

bash./install-deps-linux.sh

Generate makefiles

bashpremake5 gmake

Build

bashmake config=debug

Generate compile_commands.json for clangd (optional, for VSCodium intellisense)

bashbear -- make config=debug
That's it. Everything else is either in your repo (source, vendor headers, lua files) or installed by the script (system libs, build tools).
The only gotcha is VSCodium itself — the install script doesn't set that up. If you want it on the new machine add the repo and install it as we did earlier, then install the CodeLLDB and clangd extensions manually. You could add that to the script too if you want it fully automated.
